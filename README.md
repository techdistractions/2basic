# 2basic
A lightweight BASIC programming environment for OS/8088, featuring an interpreter, forms, events, graphics, and resource support.

A quick proof of concept to see how OpenAI CODEX could help me write a mini BASIC interpreter for os/8088. It is probably "too basic" to be useful (pun intended) but you might get some fun out of it.

.BAS can be written in plain notepad or manually typed in the console :-)
